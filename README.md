# Zepto Product & Sales Data Analysis using SQL

## 📌 Project Overview

This project analyzes Zepto product data using **PostgreSQL** to identify product, pricing, discount, inventory, and revenue insights.

## 🛠️ Tools Used

* PostgreSQL
* SQL
* Data Cleaning
* Data Analysis

## 🔍 Key Analysis

* Product categories and stock status
* Top discounted products
* High-priced out-of-stock products
* Estimated revenue by category
* Average discounts by category
* Price per gram analysis
* Product weight classification
* Inventory weight by category

## 🎯 Objective

To use SQL to clean, analyze, and extract meaningful business insights from Zepto's product dataset.
